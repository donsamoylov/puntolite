# PuntoLite

Мини-«Пунто» для macOS: мгновенная смена языка по **Fn** и исправление текста, набранного не в той раскладке.

| Клавиши | Что делает |
|---|---|
| **Fn** | Переключает EN ⇄ RU без системной задержки. Работает даже при выключенном приложении |
| **Fn + Space** | С выделением — конвертирует выделенное. Без выделения — находит и исправляет слова не в той раскладке в тексте до курсора (до 3000 символов). Повторное нажатие откатывает |

Приложение живёт в строке меню (значок 文A), без иконки в Dock, и запускается при входе.

## Установка

1. Скачайте **PuntoLite.dmg** со страницы [Releases](../../releases/latest).
2. Откройте DMG и перетащите PuntoLite в «Программы».
3. Запустите. При первом запуске macOS напишет, что разработчик не подтверждён:
   **System Settings → Privacy & Security → внизу «PuntoLite was blocked» → Open Anyway**.
4. Дайте доступ: **Privacy & Security → Accessibility → PuntoLite** (окно откроется само).

При первом запуске приложение само настраивает Fn: переназначает его в F18 (`hidutil`, переживает перезагрузку) и назначает F18 на смену языка в системных сочетаниях. Переключение работает средствами macOS, поэтому без задержки и даже когда PuntoLite выключен.

Fn как модификатор (Fn+стрелки, Fn+F1–F12) при этом не работает. Вернуть всё как было: меню 文A → «Вернуть стандартный Fn и выйти».

## Обновления

Приложение раз в сутки проверяет Releases и предлагает обновиться. Вручную — меню 文A → «Проверить обновления…».

## Выпуск новой версии

```bash
git tag v1.1.0 && git push origin v1.1.0
```
GitHub Actions соберёт универсальное приложение (Apple Silicon + Intel), DMG и ZIP и опубликует релиз.

### Один раз: сертификат подписи

Без постоянного сертификата у каждой сборки новая подпись, и macOS сбрасывает разрешение Accessibility после каждого обновления.

```bash
scripts/make-cert.sh     # затем выполнить две команды gh secret set, которые он напечатает
```

## Локальная сборка

```bash
scripts/build.sh            # build/PuntoLite.app
scripts/build.sh --package  # + build/PuntoLite.dmg и .zip
```
Нужны Xcode Command Line Tools (`xcode-select --install`).
